KNOLLWOOD PAGES CMS - QUICK START

1. Unzip this folder.
2. In your GitHub Knollwood repository, upload/replace ALL files from this package.
3. Confirm .pages.yml is visible in the repository root.
4. Confirm the data folder contains:
   - site.json
   - products.json
   - events.json
   - faqs.json
5. Confirm the media/images folder exists.
6. Go to https://app.pagescms.org and sign in with GitHub.
7. Open your Knollwood repository.
8. Edit Site Content, Products, Craft Fairs & Events, or FAQs.
9. Save. GitHub Pages will update automatically.

You should not need to edit index.html for normal website updates.
